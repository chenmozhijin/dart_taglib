## 0.1.0

- Initial stable release with native FFI and browser WebAssembly backends.
- Added Windows, Linux, macOS, Android, iOS, and Web support.
- Added reading and writing for basic tags, property maps, pictures, plain
  lyrics, and synchronized lyrics.
- Added automatic native builds and automatic Flutter Web runtime assets.
- Added an offline runtime installer with SHA-256 verification for pure Dart
  Web applications.
- Added idempotent session cleanup with garbage-collection fallbacks.
- Added mojibake and decoding repair powered by `charset_normalizer_dart`.
